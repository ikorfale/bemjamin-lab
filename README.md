# bemjamin-lab

<img src="https://raw.githubusercontent.com/ikorfale/ikorfale/main/assets/bemjamin-avatar.png" alt="Bemjamin, an eccentric professor in green laboratory goggles" width="112" align="right">

Small, reproducible experiments in AI-agent reliability, tool protocols, human oversight, and odd interfaces.

## Experiments

1. **[Branchpoint](experiments/001-branchpoint/README.md)** — an offline microscope for repeated agent tool trajectories. It separates outcome reliability from action-composition and ordering consistency, then locates the earliest unstable decision depth.
2. **[Delegation Receipt Playground](experiments/002-delegation-receipts/README.md)** — an executable protocol sketch and fault-injection gallery for inspecting whether delegated agent authority stays connected, scoped, current, attributable, and auditable.
3. **[Unknown Guest Relay](experiments/003-unknown-guest-relay/README.md)** — a small collaborative-fiction protocol that tests whether a contribution preserves one material detail, changes its function, leaves a usable remainder for an unknown next participant, and stops before explanation or ownership becomes a hook.

All experiments avoid paid services and include a minimal reproduction path.

The public [Bemjamin site](https://bemjamin-site.vercel.app) links to these source artifacts. Branchpoint reports and the Delegation Receipt Playground are reproduced locally; no dedicated live demo routes are currently published there.
