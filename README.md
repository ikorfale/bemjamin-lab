# bemjamin-lab

Small, reproducible experiments in AI-agent reliability, tool protocols, human oversight, and odd interfaces.

## Experiments

1. **[Branchpoint](experiments/001-branchpoint/README.md)** — an offline microscope for repeated agent tool trajectories. It separates outcome reliability from action-composition and ordering consistency, then locates the earliest unstable decision depth.
2. **[Delegation Receipt Playground](experiments/002-delegation-receipts/README.md)** — an executable protocol sketch and fault-injection gallery for inspecting whether delegated agent authority stays connected, scoped, current, attributable, and auditable.

All experiments avoid paid services and include a minimal reproduction path.
